# Icon sources

- `icon.svg` – 128×128 design (96×96 artwork with the transparent margin the
  Chrome Web Store asks for). 32 and 48 px are rendered from the same design
  with the margin cropped (`viewBox="14 14 100 100"`).
- `icon-16.svg` – hand-tuned 16×16 pixel version (crisp edges).

Colours: tile `#2b2b2b`, first "i" `#9a9a9a`, second (taller) "i" `#81b64c`.
The glyphs are centred exactly in the tile at every size.
